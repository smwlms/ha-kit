# Screenshots

Two sets:

- **[Real house](#real-house)**: the Home Assistant the kit modules come from. Names, places, cameras and maps
  are masked, and some views are omitted on purpose. Its interface is in Dutch (`house.language: nl`).
- **[Kit demo](#kit-demo)**: the kit's own screens, rendered from the modules with fictional data
  (people, cars and places are made up).

The real house is where the modules were taken from, so its views are close to, but not identical with, what the
kit renders. Click an image for the full size.

## Real house

Real house, names/places/cameras/maps masked; some views omitted on purpose. Numbers (energy, prices,
temperatures) are real and not masked. Each image links to the desktop view; the phone version is linked below it.
